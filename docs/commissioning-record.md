明确标注单位：rad、rad/s、rad/s²；官方 LeRobot 公共坐标使用 deg，原始电机方向单独记录。
URDF 的限位不直接作为现场软限位；不要通过撞机械端点来确定范围。

停止行为分别记录：操作停止、反馈超时、通信中断、失能、急停与断电。
每项记触发方式、现场支撑措施、实际运动/重力行为、恢复步骤及是否已验证。
保持与失能是不同操作，现场确认前不将任一操作作为通用停止策略。

按顺序签记阶段结果：安装接线 → 1–7 在线/反馈 → 校零/参数回读 → 单关节小动作
→ 夹爪 → 短轨迹 → 空壶抓放 → 相机/示教 → 采集训练。
仅填写已经现场验证的阶段；本项目的软件报告不代替这些记录。
